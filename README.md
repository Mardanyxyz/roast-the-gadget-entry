One original line (108 characters) roasting a gadget I use every day, entered in the [make.fun competition](https://make.fun/c/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

`main.ts` writes the roast to `/output/entry.txt`:

> My robot vacuum swallowed its own charging cable, then beeped for help from under the couch like the victim.

Run it with Node 22+ from any directory: `node main.ts`.
